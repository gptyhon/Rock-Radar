# S2 动态背景

适用分支：`react-s2`。更新日期：2026-11-16。

## 打开与对比

执行 `npm start`，访问 `http://localhost:3003/radar`。管理页的展示按钮指向同一地址，默认启用 S2；`?theme=s2` 兼容此前的显式预览链接。

| 入口 | 背景 |
| --- | --- |
| `/radar` | S2，高光场景、增强动态 |
| `/radar?theme=original` | React 页面使用原背景系统 |
| `/legacy/radar` | 原单 HTML 基线 |

生产运行先执行 `npm run build`，再执行 `npm run start:next`。`npm run start:legacy` 启动的是旧 HTML 服务。新旧服务默认都使用 3003，同时运行时需用 `PORT` 分配不同端口。

## 视觉与构图

视觉依据是此前提供的 S2 视频参考：蓝紫霓虹、漫画网点、斜切色块、卡牌舞台与四角星。背景采用 Canvas 重绘，不是游戏原始素材。参考视频分析及拼图保存在本地历史备份中，不是当前仓库的运行依赖。

当前背景按雷达与人物内容重新组织：

- 雷达与六维标签周围减少色块、粒子和亮线。
- 人物黑框与柔和紫色边缘绑定在立绘容器上，跟随羁绊换行和图片大小变化，框与人物共用中心。
- 紫色斜切装饰靠近画面边角，青蓝光带移至底边。
- 背景与展示舞台采用相同的等比完整适配、水平和垂直居中；较高窗口用边缘颜色延展填充。
- “货币战争”下方增加“入画奇航”背景字样。

人物框内采用 S2 漫画舞台语言：深蓝紫底、斜切分格、印刷网点、青蓝角标、四色纸片与四角星。色块在两侧轻微错位移动，宽幅羽化辉光间歇拂过后层；角色登场时分格从两侧平滑入场（1.05 秒，起止速度与加速度均为零）。所有效果绘制在 `#photoFxCanvas`，层级低于主立绘、变体和二段过渡图，并受人物容器裁切，不覆盖脸部或羁绊。此效果遵循 `PHOTO_FX_ENABLED` 和 `PHOTO_FX_INTENSITY`；当前配置已启用，强度保留 0.75。

外围沿底边斜带安排四色纸片翻动，左下角以分批弹出的纸片和四角星形成漫画式标点，保留原有霓虹导轨扫光。没有额外的旋转圆环、流体彩带或星云雾光。

视觉取向与项目原有 S2 视频参考记录一致；[官方赛季说明](https://www.miyoushe.com/wd/article/79258376)中的漫画合作主题也作为方向核对依据。此处是适配雷达展示页的重绘，并非游戏 UI 的逐帧复刻。

普通场景使用低对比舞台、网点与边缘斜带；高光场景增加霓虹边框、反光带和星芒。角色布局、评分和原有播放节奏未因背景接入而重写。

## 控制与状态

顶部工具条提供普通／高光场景、轻微／增强动态、单独暂停／继续背景及原版对比。全屏与片尾时隐藏工具条。

- 空格沿用原播放／暂停逻辑；背景是独立的环境动画，暂停演出不等于暂停背景。
- “暂停背景”控制全部 S2 动态，包括人物框内与外围动画。`P` 键沿用背景效果开关，两者任一关闭时这些效果保持静止，底图仍保留。
- 系统开启“减少动态效果”时，进入页面默认暂停 S2 背景。
- 普通／高光为手动选择，不自动跟随 MVP、抽卡或角色专场。
- 所有选择只保留在当前页面会话中，刷新恢复默认，不写入 `data.json` 或专场配置。

轻微模式降低分格、网点和纸片的运动速度、减少纸片数量；增强模式增加色块浮动、光带扫光、彩纸翻转、星芒喷涌和稀疏斜向流星。循环按同一场景时间计算，变化错开出现。

## 实现边界

| 文件 | 职责 |
| --- | --- |
| `src/radar/RadarPage.tsx` | 解析主题参数，创建背景并交给引擎，管理页面挂载与清理 |
| `src/radar/engine.js` | 在原背景和人物后层绘制入口调用 S2 渲染器 |
| `src/radar/themes/s2-background.js` | 背景几何、静态缓存、循环动画、缩放与资源释放 |
| `src/radar/themes/s2-portrait.js` | 人物后层漫画分格、网点、辉光拂过、纸片与入场动效 |
| `src/radar/themes/S2PreviewControls.tsx` | 背景工具条；控件键盘事件不触发全局角色切换 |
| `src/radar/themes/s2-preview.css` | 隐藏原底层背景，调整雷达暗色遮罩及工具条样式 |

S2 复用原主帧循环，不创建独立 RAF。渲染器对输入帧间隔限制在 0–50 ms，缓存静态层，外围背景最多每秒重绘 30 次，再合成到现有 `#particles-canvas`；人物后层直接使用同一主帧循环的连续时间逐帧绘制，避免分格入场受到背景低频缓存限制。页面隐藏和片尾不继续更新背景，卸载时释放缓存。

S2 尚未接入管理页的 `BG_EFFECT_MODE`、`BG_EFFECT_CONFIG`、专场背景配置或音频响应。修改这些参数后，应在原版模式检查效果；S2 背景不会随这些参数变化。角色专场的其余样式、转场、抽卡逻辑继续运行。

## S2 开幕与平均雷达

默认 S2 开幕以「入画奇航」为副标题，和「平均值」共用雷达页的「高光揭幕」背景。背景继续响应工具条的场景、动效强度和暂停设置。进入「平均值」时，中央略压暗，衬托依次展开的雷达线。各维度名称下显示对应均值（最多两位小数，百分比按配置换算）。

按空格或点击「按空格开始」启动原音乐时间轴，开幕总时长继续读取 `INTRO_WAIT_TIME`（至少 5200 ms）。`theme=original` 保留原开幕。标题继续读取管理页的 `INTRO_TITLE_MAIN`。

- `S2IntroOverlay.tsx` / `s2-intro.css`：开幕布局与中央暗角。引擎将现有背景画布的同一帧绘制到开幕层，沿用主循环与动效时间。
- `s2-intro.js`：使用现有 `avgScorePerDim` 和 `getRadarRatio` 绘制均值，包含已启用的二段形态；超过上限的均值扩展图表显示范围，不裁成 100%。
- 系统「减少动态效果」开启时，背景默认暂停，雷达线直接显示完整数值。
- `tests/replica/s2-intro.spec.ts` 验证开场与雷达背景帧一致、含二段的平均比例、超过上限、八维布局、三种窗口比例、减少动态效果和播放交接。
