# React 迁移与验证记录

日期：2026-11-16。基线：`hktv-new-version @ ba1d92b`，提交说明 `feat: expand radar management and fix gacha transitions`。

本文记录原样迁移阶段。随后增加的 S2 背景与默认启动入口调整见 [S2 背景预览](s2-background-preview.md)；当前默认使用 S2，原版回归通过 `?theme=original` 访问。

## 范围

原样迁移阶段以 `hktv-new-version @ ba1d92b` 的单 HTML 为基线，保留界面、动效、播放节奏和数据格式。当前 `react-s2` 在此基础上添加独立 S2 背景；原版画面对比仍可运行。此前基于 `main` 的实验代码不参与当前构建。

原 `index.html`、`admin.html`、`data.json`、`public/js/` 和 `public/css/` 保持不变。新版分支已有的专场、角色位置、角色对比、专家标记、羁绊/装备图、中途形态、新版背景效果、音乐延迟与抽卡交接逻辑继续使用。

## 结构

| 路径 | 职责 |
| --- | --- |
| `app/` | 两个轻量 HTML 入口 |
| `src/app/` | React 挂载和开发/生产 HTTP 服务 |
| `src/radar/components/` | 原舞台、片头、抽卡、专场、背景、品牌层、媒体和时间轴 |
| `src/radar/defaults.js` | 本分支原有默认配置，每次挂载创建新副本 |
| `src/radar/engine.js` | 原 Canvas、时间轴、演出和交互内核 |
| `src/admin/components/` | 六个页签和弹窗的原布局 |
| `src/admin/controller.js` | 原编辑逻辑与动态列表，包含角色对比、位置与专场 |
| `src/shared/runtimeScope.js` | 页面卸载时回收帧、计时器、事件、请求、图片回调和媒体 |
| `server.js` | 原 API 的可复用工厂；独立执行时仍启动原 HTML 版 |
| `tests/replica/` | 基于本分支原 HTML 的浏览器对照 |

React 管理页面结构和生命周期；原复杂演出、动态表单暂保留为独立 JavaScript 模块，以降低行为改变风险。动态表单通过单一控制器桥接保持原事件语义，静态按钮使用 React 事件。原背景、专场、对比、位置和音乐公共模块继续使用 `public/js/` 原文件。

原内联 CSS 逐字拆出，Vite 在首次解析 HTML 时注入；原额外 CSS 与公共脚本保持加载顺序。这样避免将 `body` 的默认 margin 也意外纳入原 `transition: all` 动画。原样式不做重写或修错。

## 验证

- `npm run check`：类型、该分支原有五组测试、新增共享 API 与原样式／演出算法源码一致性测试，以及生产构建。
- `npm run test:replica`：两版使用相同数据，对照待机、片头、播放、暂停、切换、时间轴、抽卡、MVP、片尾、管理编辑、角色位置、角色对比和专场预览。
- 测试在内存中保存编辑结果，不写用户数据；素材使用统一测试图片、回退字体和模拟媒体播放。
- 固定随机数，展示页的 CSS 动画与 Canvas 使用统一测试时钟，保证依赖动画中布局测量的遮罩同步；管理端使用 Playwright 的稳定动画截图机制。每通道允许最多 3/255 的浏览器滤镜舍入差异，不容许其他差异像素。这验证阶段画面与操作结果，不等同于真实素材逐帧整片录制。
- 当前未接入先前实验版的 Remotion/S2 场景，也不迁入其 `workspace/project.json`。旧实验运行目录保留，但不参与当前构建。

真实音视频、外部字体和完整素材需在准备齐备后进行整片验收。原 HTML 与公共模块继续保留为可运行对照，而非仅存档文本。
